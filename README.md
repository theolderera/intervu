# C++ Quiz Master

Викторинаи интерактивии C++ барои дарс — муаллим ҳуҷра месозад, донишҷӯён бо як линк
ворид мешаванд ва дар вақти воқеӣ бозӣ мекунанд. Бе сервер, бе бақайдгирӣ.

## Чӣ гуна кор мекунад

**Муаллим (Админ)**
1. Сайтро мекушояд → «Муаллим» → **Сохтани ҳуҷраи бозӣ**.
2. Танзимот: вақти ҳар савол, шумораи саволҳо, тартиби тасодуфӣ, гузариши дастӣ/худкор.
3. Линкро нусхабардорӣ карда ба донишҷӯён мефиристад.
4. Дар давоми бозӣ **ҳама чизро мебинад**: кӣ ҷавоб дод, кӣ кадом вариантро интихоб кард,
   тақсимоти ҷавобҳо, балҳо, кӣ онлайн аст. Метавонад донишҷӯро хориҷ кунад,
   ҷавобро пеш аз мӯҳлат кушояд ё бозиро анҷом диҳад.
5. Дар охир — ҳисоботи муфассали синф ва боргирии CSV.

**Донишҷӯ**
1. Линки муаллимро мекушояд → **худкор нақши донишҷӯ мегирад**
   (интихоби «Муаллим» тамоман нест).
2. Танҳо номашро менависад ва ворид мешавад.
3. Ҷавобро интихоб мекунад → ҷавоб қулф мешавад, вале **дурустии он то тамом шудани
   вақт нишон дода намешавад**. Натиҷа ва шарҳ баъди кушодани муаллим пайдо мешавад.

## Қоидаи баҳогузорӣ

| Ҳолат | Бал |
|---|---|
| Ҷавоби дуруст | 600–1000 (ҳар қадар тезтар — ҳамон қадар зиёдтар) |
| Ҷавобҳои пайдарпайи дуруст | +50 барои ҳар кадом (то +250) |
| Ҷавоби нодуруст ё бе ҷавоб | 0 |

Вақт ва балҳоро **муаллим** ҳисоб мекунад, на браузери донишҷӯ.

## Агар донишҷӯён ворид шуда натавонанд

### Сабаби асосӣ: WebRTC аз паси NAT-и оператор намегузашт

Аломат: **3–4 нафар ворид мешуданд, боқимонда то охир дар «Пайвастшавӣ...»
мемонданд** ва бозӣ ҳеҷ гоҳ оғоз намешуд.

Сабаб: пайвасти мустақими WebRTC барои донишҷӯёне, ки бо интернети мобилӣ
(4G/5G) ё Wi-Fi-и мактаб ҳастанд, сохта намешавад — онҳо пушти NAT-и симметрӣ
мемонанд. Танҳо онҳое пайваст мешуданд, ки шабакаашон «осон» буд. Серверҳои
TURN-и ройгон низ кор намекарданд.

Ҳал: акнун ба ғайр аз WebRTC **канали эҳтиётии WebSocket** (MQTT, `wss://`)
кор мекунад. Ин трафики муқаррарии порти 443/8084 аст — аз ҳар оператор ва ҳар
firewall мегузарад ва ба NAT тамоман вобаста нест. Ду роҳ ҳамзамон фаъоланд:
кадомаш зудтар расад, ҳамон истифода мешавад; такрори паёмҳо бартараф мешавад.
Агар як брокер дастрас набошад, барнома худкор ба брокери дигар мегузарад.

> Эзоҳ: брокер ҷамъиятӣ аст, бинобар ин коди ҳуҷра калиди махфият аст.
> Барои дарс кофист; барои имтиҳони расмӣ сервери худӣ лозим.

### Се сабаби пештара (ҳамаашон ислоҳ шудаанд)

1. **Алоқаи муаллим бо сервери PeerJS канда мешуд.** Донишҷӯёни аллакай
   пайвастшуда кор мекарданд (алоқаи мустақим), вале коди ҳуҷра аз сервер
   нест мешуд ва **донишҷӯёни нав ҳуҷраро ёфта наметавонистанд**.
   Ҳоло алоқа худкор барқарор мешавад — бо ҳамон коди ҳуҷра, линк тағйир намеёбад.
2. **Донишҷӯ пас аз як кӯшиши нобарор беалоқа мемонд.** Такрор танҳо паём
   мефиристод, вале худи пайвастро аз нав намесохт. Ҳоло пайваст беохир
   барқарор карда мешавад — ҳам дар лобби, ҳам дар мобайни бозӣ.
3. **TURN набуд.** Танҳо STUN истифода мешуд, бинобар ин донишҷӯёни дорои
   интернети мобилӣ (4G/5G, NAT-и симметрӣ) умуман пайваст шуда наметавонистанд —
   танҳо онҳое, ки дар як Wi-Fi буданд. Ҳоло серверҳои TURN илова шуданд.

**Маслиҳатҳо барои дарс**
- Саҳифаи муаллимро **накушоед ва экранро хомӯш накунед** — ҳуҷра дар ҳамон саҳифа зинда аст.
- Дар панели назорат нуқтаи сабз = донишҷӯ воқеан онлайн аст, хокистарӣ = алоқа нест.
  Агар касе хокистарӣ бошад, ба ӯ гӯед саҳифаро нав кунад (ном ва балҳояш нигоҳ дошта мешаванд).
- Донишҷӯ метавонад **дар мобайни бозӣ ҳам** ворид шавад — саволи ҷорӣ фавран ба ӯ мерасад.

## Сохти техникӣ

| Файл | Вазифа |
|---|---|
| `index.html` | Чор экран: вуруд, лобби, савол, рейтинг |
| `app.js` | Мантиқи бозӣ ва протоколи шабака |
| `questions.js` | 50 саволи C++ (cout, cin, if/else, for, array) |
| `style.css` | Тарҳи визуалӣ |

**Пайвастшавӣ:** PeerJS (WebRTC) байни дастгоҳҳо + BroadcastChannel/localStorage
барои санҷиш дар як браузер. Муаллим = гиреҳи асосӣ: вақт, балҳо ва лаҳзаи кушодани
ҷавоби дуруст танҳо аз ӯ вобаста аст.

## Маҳдудият

Барнома пурра дар браузер кор мекунад, аз ин рӯ файли `questions.js` (ҳамроҳи ҷавобҳои
дуруст) ба ҳамаи иштирокчиён мерасад. Донишҷӯе, ки DevTools-ро медонад, метавонад
ҷавобро пеш аз вақт бинад. Барои имтиҳони расмӣ сервери алоҳида лозим аст —
барои дарс ва машқ ин кофист.
