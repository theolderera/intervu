# C++ Quiz Master

Викторинаи интерактивии C++ барои дарс — муаллим ҳуҷра месозад, донишҷӯён бо як линк
ворид мешаванд ва дар вақти воқеӣ бозӣ мекунанд. Бе сервер, бе бақайдгирӣ.

## Чӣ гуна кор мекунад

**Муаллим (Админ)**
1. Сайтро мекушояд → «Муаллим» → **Сохтани ҳуҷраи бозӣ**.
2. Танзимот: вақти ҳар савол, шумораи саволҳо, тартиби тасодуфӣ, гузариши дастӣ/худкор.
3. Линкро нусхабардорӣ карда ба донишҷӯён мефиристад.
4. Дар давоми бозӣ **ҳама чизро мебинад**: кӣ ҷавоб дод, кӣ кадом вариантро интихоб кард,
   тақсимоти ҷавобҳо, балҳо, кӣ онлайн аст. Метавонад донишҷӯро хориҷ кунад,
   ҷавобро пеш аз мӯҳлат кушояд ё бозиро анҷом диҳад.
5. Дар охир — ҳисоботи муфассали синф ва боргирии CSV.

**Донишҷӯ**
1. Линки муаллимро мекушояд → **худкор нақши донишҷӯ мегирад**
   (интихоби «Муаллим» тамоман нест).
2. Танҳо номашро менависад ва ворид мешавад.
3. Ҷавобро интихоб мекунад → ҷавоб қулф мешавад, вале **дурустии он то тамом шудани
   вақт нишон дода намешавад**. Натиҷа ва шарҳ баъди кушодани муаллим пайдо мешавад.

## Қоидаи баҳогузорӣ

| Ҳолат | Бал |
|---|---|
| Ҷавоби дуруст | 600–1000 (ҳар қадар тезтар — ҳамон қадар зиёдтар) |
| Ҷавобҳои пайдарпайи дуруст | +50 барои ҳар кадом (то +250) |
| Ҷавоби нодуруст ё бе ҷавоб | 0 |

Вақт ва балҳоро **муаллим** ҳисоб мекунад, на браузери донишҷӯ.

## Ҷойгиркунӣ (hosting)

Барои он ки донишҷӯён аз телефонҳои худ ворид шаванд, сайт бояд дар интернет бошад.
Роҳи осонтарин — **GitHub Pages**:

`Settings` → `Pages` → `Source: Deploy from a branch` → `Branch: main / (root)` → `Save`.

Баъди 1–2 дақиқа линк тайёр мешавад:
`https://theolderera.github.io/intervu/`

## Сохти техникӣ

| Файл | Вазифа |
|---|---|
| `index.html` | Чор экран: вуруд, лобби, савол, рейтинг |
| `app.js` | Мантиқи бозӣ ва протоколи шабака |
| `questions.js` | 50 саволи C++ (cout, cin, if/else, for, array) |
| `style.css` | Тарҳи визуалӣ |

**Пайвастшавӣ:** PeerJS (WebRTC) байни дастгоҳҳо + BroadcastChannel/localStorage
барои санҷиш дар як браузер. Муаллим = гиреҳи асосӣ: вақт, балҳо ва лаҳзаи кушодани
ҷавоби дуруст танҳо аз ӯ вобаста аст.

## Маҳдудият

Барнома пурра дар браузер кор мекунад, аз ин рӯ файли `questions.js` (ҳамроҳи ҷавобҳои
дуруст) ба ҳамаи иштирокчиён мерасад. Донишҷӯе, ки DevTools-ро медонад, метавонад
ҷавобро пеш аз вақт бинад. Барои имтиҳони расмӣ сервери алоҳида лозим аст —
барои дарс ва машқ ин кофист.
