# Quiz Master — C++ & JavaScript

Викторинаи интерактивӣ барои дарс: муаллим ҳуҷра месозад, донишҷӯён бо як линк
ворид мешаванд ва дар вақти воқеӣ бозӣ мекунанд. Бе сервер, бе бақайдгирӣ.

*Интерактивная викторина для урока: учитель создаёт комнату, студенты входят по
одной ссылке и играют в реальном времени. Без сервера, без регистрации.*

### Лотини ӯзбекӣ худкор ҳосил мешавад

Матни ӯзбекӣ дар лоиҳа **танҳо бо кирилл** нигоҳ дошта мешавад (`uz`). Лотин
(`uzl`) аз ҳамон матн бо [uz-latin.js](uz-latin.js) ҳосил мешавад: `ў → oʻ`,
`ғ → gʻ`, `қ → q`, `ъ → ʼ`. Ин маънои онро дорад, ки як тарҷума ду навишт
медиҳад ва ду алифбо ҳеҷ гоҳ аз ҳам намераванд.

Ду қоидаи муҳофизатӣ:

- Вариантҳое, ки **код ё матни айнан чопшавандаи барнома** мебошанд (яъне дар
  ҳамаи забонҳо якхелаанд), ҳеҷ гоҳ тарҷума ё транслитератсия намешаванд —
  вагарна ҷавоби дуруст бо натиҷаи воқеии барнома мувофиқ намеомад.
- Калимае, ки ҳарфи берун аз алифбои ӯзбекӣ дорад (масалан `Ҷуфт`-и тоҷикӣ, ки
  барнома чоп мекунад), пурра бетағйир мемонад — нимтабдил намешавад.

## 🛡️ Муҳофизат / Защита

| Хатар | Ҳимоя |
|---|---|
| Касе бозӣ оғоз кунад | Пароли муаллим (SHA-256, блок пас аз 5 кӯшиш) |
| Меҳмони линк муаллим шавад | Нақш ба «донишҷӯ» қулф мешавад — ҳатто аз консол |
| «Муаллими қалбакӣ» фармон диҳад | Имзои рақамии **ECDSA P-256** дар ҳар паём |
| Ҷавоби дурустро пеш аз вақт кушоданд | `REVEAL`-и беимзо рад мешавад |
| Донишҷӯ ба ҷои дигаре ҷавоб диҳад | Ҳар донишҷӯ калиди худро дорад, «мехкӯб» мешавад |

**Чӣ тавр кор мекунад:** муаллим ҳангоми сохтани ҳуҷра як ҷуфти калид месозад.
Калиди **кушод** дар линк пас аз `#` меравад (қисми `#` ба ҳеҷ сервер фиристода
намешавад). Калиди **махфӣ** ҳеҷ гоҳ аз дастгоҳи муаллим берун намебарояд.
Ҳар паём имзо мешавад; бе калиди махфӣ имзои дуруст сохтан имконнопазир аст.

## 🧹 Кеш / Кэш

Донишҷӯён аксаран дар компютери умумии синфхона кор мекунанд. Пас аз анҷоми бозӣ
(ва ҳангоми пӯшидани таб ё хориҷ кардан) ному ID-и донишҷӯ аз дастгоҳ **пурра
тоза мешавад** — донишҷӯи навбатӣ бо номи ҳамсинфи худ ворид намешавад.
Танҳо танзими забон мемонад.

## 👨‍🏫 Муаллим / Учитель

1. Сайтро мекушояд → «Муаллим» → **парол** → «Сохтани ҳуҷраи бозӣ».
2. Танзимот: фан, вақти ҳар савол, шумораи саволҳо, тартиб, гузариши дастӣ/худкор.
3. Линкро нусхабардорӣ карда ба донишҷӯён мефиристад.
4. Дар давоми бозӣ **ҳама чизро мебинад**: кӣ ҷавоб дод, кӣ кадом вариантро
   интихоб кард, тақсимоти ҷавобҳо, балҳо, кӣ онлайн аст. Метавонад донишҷӯро
   хориҷ кунад, ҷавобро пеш аз мӯҳлат кушояд ё бозиро анҷом диҳад.
5. Дар охир — ҳисоботи муфассали синф ва боргирии CSV.

## 🎓 Донишҷӯ / Студент

1. Линки муаллимро мекушояд → **худкор нақши донишҷӯ мегирад**.
2. Танҳо номашро менависад ва ворид мешавад.
3. Ҷавобро интихоб мекунад → ҷавоб қулф мешавад, вале **дурустии он то тамом
   шудани вақт нишон дода намешавад**.

## 📶 Пайвастшавӣ

Се канал ҳамзамон кор мекунанд, то ҳеҷ кас берун намонад:

- **WebRTC (PeerJS)** — пайвасти мустақим, бо серверҳои STUN ва TURN;
- **WebSocket (MQTT)** — канали эҳтиётӣ барои интернети мобилӣ ва NAT-и симметрӣ;
- **BroadcastChannel / localStorage** — табҳои ҳамин браузер.

Паёмҳои такрорӣ бо `msg.mid` бартараф мешаванд.

**Барои синфи калон (50+ нафар):** рӯйхати иштирокчиён танҳо ҳангоми тағйир ва на
бештар аз як маротиба дар 1.2 сония фиристода мешавад; хабари «кӣ ҷавоб дод» дар
400 мс ҷамъ мешавад; вурудҳои ҳамзамон дар 700 мс як snapshot мегиранд.

### Санҷиши ҷавобҳои C++ бо компилятори воқеӣ

```bash
npm run verify:cpp
```

Ҳар порчаи коди бонкро дар контейнери `gcc:13` компилятсия ва иҷро мекунад,
натиҷаи чопро бо вариантҳои ҷавоб муқоиса менамояд ва агар ҷавоби «дуруст»
ба натиҷаи воқеӣ мувофиқ наояд, хато эълон мекунад. Саволҳое, ки маҳз хатои
компилятсияро меомӯзонанд, алоҳида тасдиқ мешаванд. Docker лозим аст.
